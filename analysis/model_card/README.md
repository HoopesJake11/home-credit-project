# Model card analysis scripts

These scripts produce every result used in [`homecredit-eda/model_card.qmd`](../../homecredit-eda/model_card.qmd). They are tracked copies of the scripts originally written into `models/model_card/`. That folder is git-ignored because it holds model objects, predictions and other large outputs.

Run every script **from the repository root**. Each one writes its outputs to `models/model_card/` (git-ignored) and modifies nothing else: not the raw data, the prepared data, the saved final model, the notebooks or the Kaggle submission.

```
"C:/Program Files/R/R-4.5.2/bin/Rscript.exe" analysis/model_card/<script>.R
```

## A fresh clone cannot run these immediately

The scripts depend on files that are not in the repository:

1. **Kaggle data** in `homecredit-eda/data/` (see the main README, *Getting the data*).
2. **Prepared data** in `homecredit-eda/data/prepared/`, created by `Rscript data_preparation.R`.
3. **The saved final model** `models/final_home_credit_xgb.rds` and the Kaggle submission `submissions/home_credit_xgboost_submission.csv`, both written by rendering `homecredit-eda/modeling.qmd` (about 10 minutes).

The model card was produced from the locally saved model listed in Step 1 (MD5 `60bc2f0e0d0a3ea69aad12a1351d72b9`). A model regenerated by re-rendering `modeling.qmd` was **not** checked for bit-for-bit equality with that file.

## Scripts, in run order

| Script | What it does | Local prerequisites | Fits models? | Approx. time |
|---|---|---|---|---|
| `step1_verify_saved_model.R` | Reloads the final model, regenerates the Kaggle predictions and compares them with the submission; records `sessionInfo()` | final model, `test_prepared.rds`, submission CSV, `sample_submission.csv` | No | seconds |
| `step2_dataset_loan_terms.R` | Loan sizes and implied pricing from the data, used by the lending-economics research ([`step2_lending_economics.md`](step2_lending_economics.md)) | `application_train.csv`, `previous_application.csv` | No | not timed (reads two large CSVs) |
| `step3_cv_calibration.R` | Reproduces the 80/20 split; five-fold out-of-fold predictions with fold-specific preprocessing; cross-fitted Platt and isotonic calibration | raw `application_train.csv` and `bureau.csv`, `train_prepared.rds`, final model (method and hyperparameters only), `data_preparation.R` | Yes (10 validation fits; the final model is untouched) | ~3.5 min |
| `step4_threshold_optimization.R` | Financial scenarios, break-even thresholds, profit curves and bootstrap | Step 3 outputs | No | ~25 s |
| `step5_holdout_evaluation.R` | Development-only model, single holdout evaluation at the frozen 0.25 threshold, financial results, initial fairness | raw data, `train_prepared.rds`, `prep_params.rds`, final model (method only), Step 3 outputs | Yes (development-only model plus a reproduction fit) | ~1.5 min |
| `step6_shap_analysis.R` | TreeSHAP on 1,000 applicants for the final model; adverse-action mapping | final model, `train_prepared.rds`, `prep_params.rds`, data dictionary, Step 3 calibrator | No | ~20 s |
| `step7_fairness_assessment.R` | Detailed holdout fairness analysis, direct-term SHAP decomposition, threshold sensitivity, risk register | Step 5 outputs (predictions, development-only model and parameters), Step 3 calibrator, raw data | No | ~70 s |

After running the scripts, render the model card from `homecredit-eda/`:

```
quarto render model_card.qmd
```

The notebook reads only saved outputs from `../models/model_card/` and stops with a clear message if any are missing. It also stops if any headline figure disagrees with the verified results.

## Notes

- Re-running a script **overwrites** its previous outputs in `models/model_card/`. Seeds are fixed. A rerun of one Step 3 fold reproduced its predictions exactly, but the full pipeline has not been re-run end to end from these tracked copies.
- R 4.5.2, xgboost 3.2.1.1, caret 7.0-1 and pROC 1.19.0.1 were used (full `sessionInfo()` is in `models/model_card/session_info.txt`). caret's built-in `xgbTree` does not work with xgboost 3.x, so the scripts reuse the custom caret method stored inside the saved model.
- [`step2_lending_economics.md`](step2_lending_economics.md) is the source-cited research record behind the financial assumptions. It is written by hand, not generated.
